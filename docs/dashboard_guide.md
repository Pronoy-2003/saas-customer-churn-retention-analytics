# Dashboard Guide

## Overview

The Power BI dashboard analyzes SaaS customer retention, churn, customer
value, and revenue risk.

The dashboard contains four pages:

1.  Home Page
2.  Executive Overview
3.  Customer Retention
4.  Customer Value

------------------------------------------------------------------------

## 1. Home Page

The Home Page provides a high-level introduction to the project and
navigation to the three analytical pages.

### Key Elements

-   Project title and business objective
-   Navigation buttons:
    -   Executive Overview
    -   Customer Retention
    -   Customer Value
-   Summary KPIs:
    -   Total Customers
    -   Retention Rate
    -   Total Revenue
    -   Revenue at Risk

### Dashboard Image

![Home Page](../screenshots/01_home_page.png)

------------------------------------------------------------------------

## 2. Executive Overview

This page provides an executive-level view of customer churn and revenue
performance.

### Key KPIs

-   Total Customers
-   Churned Customers
-   Churn Rate
-   Retention Rate
-   Churned Revenue
-   Revenue at Risk

### Key Analyses

-   Churn Rate by Subscription Plan
-   Revenue at Risk by Plan
-   Revenue Contribution by Plan

### Filters

-   Plan
-   Acquisition Channel

### Dashboard Image

![Executive Overview](../screenshots/02_executive_overview.png)

------------------------------------------------------------------------

## 3. Customer Retention

This page focuses on customer retention trends, churn timing, cohort
behavior, and acquisition-channel churn.

### Key KPIs

-   Active Customers
-   Churned Customers
-   Retention Rate
-   Churn Rate

### Key Analyses

-   Churn Rate by Monthly Tenure
-   Customer Retention Trend
-   Cohort Retention Matrix
-   Churn Rate by Acquisition Channel

### Filters

-   Cohort Month
-   Acquisition Channel

### Dashboard Image

![Customer Retention](../screenshots/03_customer_retention.png)

------------------------------------------------------------------------

## 4. Customer Value

This page focuses on customer lifetime value and revenue contribution.

### Key KPIs

-   Total Revenue
-   Average Lifetime Revenue
-   Churned Revenue
-   Revenue at Risk

### Key Analyses

-   Revenue Contribution by Plan
-   Customer Lifetime Revenue by Customer Status
-   Top Customer Value Segment
-   Revenue by Acquisition Channel

### Filters

-   Plan
-   Customer Status

### Dashboard Image

![Customer Value](../screenshots/04_customer_value.png)

------------------------------------------------------------------------

## Navigation

Use the navigation buttons at the top of each analytical page to move
between:

**Executive Overview → Customer Retention → Customer Value**

The Home Page provides the main entry point to the dashboard.

------------------------------------------------------------------------

## Currency

All monetary values are presented in **US dollars (\$)**.
